# OpenAI Game Builders Seoul 2026 규칙 요약

**확인 기준:** 2026-08-24 (KST)에 [공식 행사 페이지](https://openaigame2026.com/), [Track 1 공식 FAQ](https://openaigame2026.com/ko/news/online-warm-up-challenge-track-1), [참가 약관](https://openaigame2026.com/ko/terms)을 확인했고 실제 제출 폼 관찰은 2026-08-22 KST 기준입니다. 참가 약관은 2026-08-03 시행으로 표시됩니다. 운영진의 최신 공지와 제출 폼이 우선하며, 이 문서는 법률 자문이 아닙니다.

## 공식 요구사항

다음은 공개 안내와 약관에서 **해야 한다고 명시된 사항**입니다.

- 개인 또는 팀으로 참가하며, 팀은 최대 3명입니다. 팀 신청은 대표자 1명이 진행하고 본선에는 대표자 1명이 참석합니다(대표자 변경은 운영진 사전 승인 여부를 확인합니다).
- Track 1 제출작은 심사 기간 동안 정상 실행되는, 브라우저에서 바로 실행되는 웹 빌드여야 합니다. 별도 설치나 승인 없이 플레이 가능한 공개 링크를 제출하고, 조작법과 실행 방법을 안내합니다.
- 게임을 만드는 과정에서 Codex를 사용해야 합니다.
- 기존에 개발하던 프로젝트도 사용할 수 있습니다. 이 경우 기존 범위와 챌린지 기간 동안 새로 개발·개선한 범위를 제출 자료에 명확히 적습니다.
- 제출 필수 항목은 게임 제목, 게임 소개, 플레이 가능한 게임 링크, 게임 썸네일입니다.
- 제출물에 포함한 코드, 이미지, 영상, 음원, 폰트, 데이터, 오픈소스, AI 생성물 및 외부 에셋의 필요한 권리·사용 허락을 확보해야 합니다. 타인의 저작권·상표권·초상권·개인정보·영업비밀 등을 침해해서는 안 됩니다.

현재 공개 규정은 개발 중 Codex 사용을 요구하지만, 게임 실행 중 OpenAI API를 호출하거나 특정 OpenAI 런타임 기능을 사용하라고 요구하지 않습니다. 따라서 **Codex 개발 사용은 필수이고 런타임 OpenAI API 연동은 필수가 아닙니다.** 이후 운영진 공지가 바뀌면 최신 안내를 따릅니다.

## 권장 운영 방식

- Track 1은 로그인이 필요할 때 테스트 계정을 제공할 수 있지만, 심사 중 접근 실패 위험을 줄이려면 로그인 없는 공개 배포가 안전합니다.
- Codex 활용 과정 서술은 선택 제출이면서 가산점 항목입니다. Codex를 사용한 위치, 구현 기능, 해결한 문제, 사람이 결정한 부분과 증거를 개발 중에 계속 기록하는 것이 좋습니다.
- 필수 링크와 파일은 제출 전에 다른 계정, 시크릿 브라우저, 대상 기기에서 다시 검증하는 것이 좋습니다.

## 제출 후 수정 정책

2026-08-24에 확인한 공식 FAQ는 마감 전에 수정본 전체를 다시 제출할 수 있고, 여러 번 제출하면 운영진은 원칙적으로 가장 최신에 제출된 버전을 기준으로 확인할 예정이라고 안내합니다. 최신본 사용이나 기존 제출 대체를 무조건 보장하는 표현은 아니며, 개별 폼 필드를 직접 편집할 수 있다고 열거한 것도 아닙니다. 따라서 수정이 필요하면 마감 전에 완전한 수정본을 재제출하는 방식으로 운용합니다.

FAQ는 제출한 URL에 연결된 게임 자체의 업데이트에는 별도 제한이 없다고 안내합니다. 다만 늦은 업데이트는 심사에 반영되지 않을 수 있고 제출 링크는 계속 정상 플레이 가능해야 합니다. 따라서 FICTOR는 한 번 제출한 **동일한 안정 URL**에서만 게임을 개선하며, URL 교체 가능성을 전제로 운용하지 않습니다.

공개 자료의 확인 결과는 다음과 같습니다. 세부 근거와 관찰 시각은 [T061 제출 수정 정책 근거](decisions/t061-submission-edit-policy-evidence-2026-08-24.md)에 분리해 기록합니다.

| 질문 | 공개 근거 판정 | 운영 의미 |
| --- | --- | --- |
| 정확한 접수 cutoff | `UNKNOWN` | 날짜 표시는 8월 26일까지지만 시각은 별도 공식 근거가 필요합니다. |
| 마감 전 수정본 전체 재제출 | `YES` | 운영진은 원칙적으로 가장 최신에 제출된 버전을 기준으로 확인할 예정입니다. 최신본 사용·대체 보장은 아니며 개별 필드 편집 가능 여부도 열거되지 않았습니다. |
| 제출 후 동일 URL의 게임 콘텐츠 업데이트 | `YES` | 동일 URL을 유지합니다. 늦은 변경이 심사에 보인다는 보장은 없습니다. |
| 마감 후 제출 폼 정보 수정 | `UNKNOWN` | 약관은 가능 여부와 방법을 확정하지 않고 운영 사무국에 문의할 수 있다고만 안내하며, 문의 의무를 부과하지 않습니다. |
| 마감 후 플레이 URL 교체 | `UNKNOWN` | 허용을 가정하지 않습니다. |

## 제출 폼 제한과 선택 항목

아래 값은 2026-08-22 KST에 실제 제출 폼의 visible UI와 DOM을 대조한 결과입니다. `required`와
`maxlength`는 form control 속성이고, `권장`은 UI 안내일 뿐 file input의 강제 제한으로 해석하지 않습니다.

| 항목 | 폼 관찰 |
| --- | --- |
| 게임 제목 | required; DOM `maxlength=80` |
| 게임 소개 | required; 200자 제한 |
| 플레이 가능한 URL | required |
| 썸네일 | required; file accept는 JPEG/PNG. 16:9와 최대 10MB는 UI recommendation |
| 데모 URL | optional |
| Codex 활용 서술 | optional; DOM `maxlength=5000` |

폼은 Google login/account, 국가, 생년월일, 신청자·팀·연락처, 본선 참석과 동의 항목도 요구합니다.
이 개인정보는 제출자가 라이브 폼에 직접 입력하며 값·화면 캡처·네트워크 payload를 저장소나 공개
증거에 캡처·커밋하지 않습니다. 데모 URL과 Codex 서술은 선택 항목입니다. 게임 링크는 심사 기간 내
누구나 비용 없이 접근할 수 있는지 제출 직전에 다시 확인합니다.

## 심사

공식 페이지에 공개된 공통 항목은 다음 5가지입니다. **항목별 배점 또는 가중치는 공개되어 있지 않습니다.** 아래 설명은 페이지의 항목을 쉽게 점검하기 위한 요약이며 점수를 보장하지 않습니다.

| 항목 | 확인할 질문 |
| --- | --- |
| Playability | 게임이 실제로 작동하고 핵심 플레이를 끝까지 체험할 수 있습니까? |
| Originality | 아이디어와 플레이 방식이 독창적입니까? |
| Codex Collaboration | Codex를 효과적으로 활용했으며 그 과정을 설명할 수 있습니까? |
| Release Potential | Hive를 통해 서비스를 확장할 가능성을 보여 줍니까? |
| Presentation | 게임과 개발 과정이 발표·시연으로 명확히 전달됩니까? |

본선은 Track 1 출품작을 대표자가 직접 발표·시연하는 형식입니다. 현장 프로그램에는 Track 1 최대 3분 엘리베이터 피치가 안내되어 있습니다.

## Track 2: 현장 5시간 빌드

- Track 1 본선 진출팀의 대표자 1명만 참가할 수 있습니다.
- 2026-08-31 서울 현장에서 주제를 공개하고, 제한 시간(공개 페이지에는 5 Hour Build로 표시)에 Codex를 사용해 브라우저에서 실행되는 게임을 개발합니다.
- 행사 사이트에 결과물을 공개하고 현장 인기 투표를 진행합니다. 세부 제출 시각·주제·운영 방식은 당일 안내를 따릅니다.
- 로그인·설치·별도 승인 없이 실행되는 공개 링크가 요구됩니다.

Track 2는 Track 1의 사전 제출을 대체하지 않으며, Track 1 본선 진출이 전제입니다.

## 보상

- 본선 참가자 전원에게 미화 100달러 상당의 OpenAI 크레딧이 안내되어 있습니다.
- Track 1 수상 보상은 총 미화 50,000달러 상당의 OpenAI 크레딧과 ChatGPT Pro 1년 구독권입니다: 대상 1팀 15,000달러, 최우수상 1팀 10,000달러, 우수상 1팀 7,500달러, 장려상 5팀 각 3,500달러 상당입니다.
- Track 2는 현장 투표 상위 3팀에 ChatGPT Pro 1년 구독권이 안내되어 있습니다.
- 보상은 팀당 대표자 1인이 수령하는 것으로 안내되어 있습니다. 지급 시기·세금·계정·사용 기간과 같은 조건은 지급 주체의 추가 안내를 확인합니다.

## IP, 공개, 법률 및 실격

- 제출작의 저작권과 기타 지식재산권은 원칙적으로 참가자에게 남습니다. 다만 심사, 행사 운영, 기록, 결과 발표, 홍보, 웹사이트·SNS 게시 및 아카이브를 위해 제목·설명·썸네일·영상·플레이 화면·발표 자료 등의 사용을 주최사·주관사에 허락하게 됩니다.
- 비공개 소스코드와 비공개 기술 자료는 별도 동의 없이 공개하지 않는다고 약관에 적혀 있지만, 제출 자료에 영업비밀·비공개 정보를 넣지 않는 것이 안전합니다.
- 불법·유해 콘텐츠, 차별·혐오·음란물, 폭력 조장, 개인정보 무단 수집, 악성 코드·보안 침해 기능, 표절, 타인 결과물 무단 사용, 허위 정보, 대리 참가, 투표 조작 및 심사 방해를 금지합니다.
- OpenAI 및 외부 플랫폼·라이브러리·엔진·호스팅의 약관·정책·라이선스를 참가자가 확인해야 합니다. API 키·비밀번호·개인정보를 공개 링크, 저장소, 영상에 포함하지 않습니다.
- 약관·안내·법령 위반, 권리 침해, 심사 기간 접속 불가, 부정행위 등이 확인되면 접수 거절, 심사 제외, 본선·수상 취소, 공개 중단, 보상 지급 보류 또는 환수가 될 수 있습니다.

FICTOR의 Higgsfield 출력 권리, 초기 상표 검색과 AI 아트 표기 판단 자료는 [T009 아트 정책 조사](legal/art-policy-decision-2026-08-11.md)에 분리해 기록합니다. 이 조사만으로 이미지 생성이나 공개 타이틀이 승인되지는 않습니다.

### 수상작의 4개월 우선협상권

수상자는 공모전 종료일로부터 **4개월간** 수상작의 사업화·투자·퍼블리싱·공동개발·상업적 이용에 관해 주최사와 주관사에 우선협상권을 부여합니다. 제3자와 계약하거나 구체적 협상을 시작하기 전에 서면으로 협상 기회를 제공해야 하며, 주최사·주관사가 통지 후 30영업일 이내 의사를 밝히면 이후 30일 동안 우선적으로 성실히 협상합니다. 합의가 없으면 제3자와 자유롭게 협상할 수 있습니다. 이는 협상 기회의 우선순위이지 사업화 계약 체결 의무나 사업화 강제가 아닙니다. 수상 가능성이 있는 팀은 외부 계약 전에 약관 제14조와 별도 서면 계약을 검토해야 합니다.

## 확인이 필요한 열린 질문

공개 자료만으로 다음 사항은 확정할 수 없습니다. 운영진 공지나 문의 채널로 확인하고 기록합니다.

- 2026-08-26 Track 1 접수의 정확한 cutoff. countdown 구현과 사용자 제공 화면 관찰은 참고 추론일 뿐 운영 보증이 아닙니다.
- 마감 후 제출 폼 정보 수정 가능 여부·방법과 플레이 URL 교체 가능 여부. 참가 약관은 운영 사무국에 문의할 수 있다고만 안내하며 문의 의무를 부과하지 않습니다.
- 서울 본선의 정확한 행사장 주소, 출입 절차, 장비·네트워크 제공 범위
- Track 2의 당일 주제, 정확한 제출 시각, 현장 계정·배포 절차
- 심사 5개 항목의 배점·가중치, 동점 처리 및 선정 세부 기준
- 보상 지급의 계정 자격, 유효기간, 세금·제세공과금, 팀 내부 배분 방식
