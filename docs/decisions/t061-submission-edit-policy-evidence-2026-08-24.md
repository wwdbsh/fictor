## 사실과 운영 가정

공식 FAQ로 확인된 사실은 마감 전 수정본 전체 재제출, 운영진이 원칙적으로 가장 최신 제출 버전을 기준으로 확인할 예정이라는 안내, 동일 제출 URL의 게임 업데이트 허용입니다. 최신본 사용·대체는 보장되지 않으며, 정확한 cutoff, 마감 후 제출 폼 정보 수정, 마감 후 URL 교체도 확인되지 않았습니다.

프로젝트 소유자의 운영 전략은 다음과 같습니다.

1. T047을 포함한 release·배포·QA·제출의 각 별도 gate를 모두 충족하고 승인받은 뒤에만 현재 후보를 먼저 제출합니다.
2. 제출 뒤 직접 플레이테스트하며 완성도를 높이고, 게임 업데이트는 제출한 동일한 안정 URL에만 반영합니다.
3. URL 교체 가능성이나 늦은 업데이트의 심사 반영을 가정하지 않습니다.
4. 정확한 cutoff가 공식 근거로 확인되기 전에는 countdown 추론을 제출 시각 보증으로 사용하지 않습니다.

## 차단과 다음 증거

T061과 T047은 계속 차단 상태입니다. T061 미충족으로 이 문서는 Draft/checkpoint일 뿐이며 merge 또는 Task complete로 처리할 수 없습니다. release·배포·제출은 수행하지 않았습니다. 다음 판단에는 countdown이 아닌 공식 근거로 정확한 cutoff를 확인하고, 선택적으로 운영 사무국에 문의해 마감 후 제출 정보 수정 및 URL 교체 정책을 확인한 기록이 필요합니다. 약관은 이 문의를 의무화하지 않습니다. 문의를 하더라도 저장소에는 폼, payload, 이메일, 쿠키, 계정, 연락처 또는 개인정보를 보관하지 않습니다.
