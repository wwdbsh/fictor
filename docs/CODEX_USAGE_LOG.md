# Codex 사용 기록 템플릿

Codex를 사용한 개발 단위마다 아래 한 블록을 복사해 작성합니다. 제출 시 선택 서술(최대 5,000자)의 근거와 팀 내부 회고에 함께 사용할 수 있습니다.

## 기록

- 날짜(KST): `YYYY-MM-DD`
- 목표: `무엇을 만들거나 바꾸려 했는가`
- Codex 사용: `프롬프트/세션/작업 방식과 적용한 파일 또는 영역`
- 구현 결과: `실제로 동작하게 된 기능·변경`
- 해결한 문제: `문제의 증상과 해결 방법`
- 사람의 결정: `요구사항·디자인·기술 선택·검토·수정 중 사람이 판단한 부분`
- 증거/커밋: `커밋 해시, PR, 테스트, 스크린샷, 실행 링크 등`
- 챌린지 기간 신규 작업인가: `예/아니오 — 기존 범위와 새 범위를 구분해 기재`

## 제출용 요약 메모

`Codex를 어디에 사용했는지, 어떤 기능을 구현했는지, 어떤 문제를 해결했는지, 사람이 직접 결정한 부분을 5,000자 이내로 요약합니다.`
